# QtScrcpy 项目打包方式

## 项目概述

QtScrcpy 是一个基于 Qt 框架开发的 Android 设备投屏和控制工具，支持 Windows、macOS 和 Linux 三大平台。项目采用 C++ 和 Qt 框架开发，使用 CMake 作为构建系统。

## 构建系统

QtScrcpy 项目使用 CMake 作为构建系统，支持跨平台构建。项目通过不同的构建脚本来适配各个操作系统。

## 各平台打包方式

### Linux 平台打包

#### AppImage 打包

Linux 平台使用 AppImage 格式进行打包，这是一种便携式的 Linux 应用程序格式，用户无需安装即可运行。

**打包脚本**: [package_appimage.sh](d:\QtScrcpy\ci\linux\package_appimage.sh)

**打包流程**:
1. **环境检测**: 自动检测 Qt 安装路径，如果未设置 `ENV_QT_PATH`，则会在常见路径中查找
2. **创建目录结构**: 创建 AppDir 目录结构，包含 `/usr/bin`、`/usr/lib`、`/usr/share/applications` 等标准路径
3. **复制文件**:
   - 可执行文件 (QtScrcpy) 从 `./output/x64/$build_mode` 复制到 AppDir
   - 音频传输脚本和 APK (sndcpy.sh 和 sndcpy.apk) 复制到 AppDir
   - 自定义按键映射文件 (keymap) 复制到 AppDir
   - 配置文件 (config) 复制到 AppDir
   - ADB 工具和 scrcpy-server 复制到 AppDir
4. **图标处理**: 处理应用程序图标，生成多种尺寸的图标
5. **创建桌面文件**: 生成 `.desktop` 文件用于应用程序启动
6. **创建元信息文件**: 生成 `.appdata.xml` 文件用于应用商店展示
7. **创建 AppRun 脚本**: 用于设置环境变量和启动应用程序
8. **下载 linuxdeploy 工具**: 自动下载 linuxdeploy 和 linuxdeploy-plugin-qt 工具
9. **部署 Qt 依赖**: 使用 linuxdeploy 工具自动收集和部署 Qt 库依赖
10. **生成最终 AppImage**: 创建可分发的 AppImage 文件

### Windows 平台打包

#### 发布包制作

Windows 平台使用批处理脚本进行打包，生成可直接运行的应用程序包。

**构建脚本**: [build_for_win.bat](d:\QtScrcpy\ci\win\build_for_win.bat)
**发布脚本**: [publish_for_win.bat](d:\QtScrcpy\ci\win\publish_for_win.bat)

**构建流程**:
1. **环境配置**: 设置 Visual Studio 环境变量和 Qt 路径
2. **CMake 配置**: 使用 CMake 生成 Visual Studio 项目文件
3. **编译**: 使用 CMake 构建项目

**发布流程**:
1. **创建发布目录**: 准备发布所需的目录结构
2. **复制文件**:
   - 从构建输出目录复制可执行文件到发布目录
   - 复制 ADB 工具到发布目录
   - 复制 scrcpy-server 到发布目录
   - 复制 keymap 目录到发布目录
   - 复制 config 目录到发布目录
3. **Qt 依赖部署**: 使用 `windeployqt` 工具自动收集和部署 Qt 依赖库
4. **清理冗余文件**:
   - 删除不需要的 iconengines 目录
   - 删除 translations 目录
   - 删除不必要的图像格式插件（保留 qjpeg.dll 用于截图功能）
   - 删除 vc_redist 安装包
5. **部署运行时库**:
   - 复制 Visual C++ 运行时 DLL 文件到发布目录
   - 区分 x86 和 x64 架构复制对应的 DLL 文件

### macOS 平台打包

#### DMG 打包

macOS 平台使用 DMG 格式进行打包，通过 `macdeployqt` 工具来部署依赖。

**构建脚本**: [build_for_mac.sh](d:\QtScrcpy\ci\mac\build_for_mac.sh)
**发布脚本**: [publish_for_win.sh](d:\QtScrcpy\ci\mac\publish_for_mac.sh)

**构建流程**:
1. **环境配置**: 设置 Qt 路径和 macOS 架构参数
2. **CMake 配置**: 使用 CMake 生成项目文件，设置架构参数
3. **编译**: 使用 CMake 构建项目

**发布流程**:
1. **创建发布目录**: 准备发布所需的目录结构
2. **复制文件**:
   - 从构建输出目录复制应用程序包到发布目录
   - 复制 keymap 目录到应用程序包内
3. **Qt 依赖部署**: 使用 `macdeployqt` 工具自动收集和部署 Qt 依赖
4. **清理冗余文件**:
   - 删除不需要的 iconengines 插件
   - 删除不需要的图像格式插件
   - 删除 virtualkeyboard、printsupport、platforminputcontexts 等插件
   - 删除多余的 Frameworks

## 通用打包要素

### 依赖项
- Qt 框架 (Windows: msvc2019, Linux: gcc_64, macOS: clang_64/macos)
- ADB 工具 (用于设备连接)
- scrcpy-server (Android 服务端)
- 自定义按键映射脚本 (keymap 目录)
- 配置文件 (config 目录)

### 构建输出
- 可执行文件 (QtScrcpy)
- 音频传输脚本 (sndcpy.sh)
- 音频传输 APK (sndcpy.apk)
- 第三方依赖库

### 平台特定考虑
- **Windows**: 需要 Visual C++ 运行时库
- **Linux**: 需要适当的 Qt 库和系统库
- **macOS**: 需要正确的代码签名和权限

## 打包注意事项

1. **架构兼容性**: 确保构建的架构(x86/x64/arm64)与目标系统匹配
2. **依赖完整性**: 确保所有必要的依赖库都被正确部署
3. **许可证合规**: 遵循所使用库的许可证要求
4. **数字签名**: 在 Windows 和 macOS 上考虑应用数字签名
5. **大小优化**: 删除不必要的文件以减小发布包大小
