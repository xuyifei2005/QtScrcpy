# QtScrcpy 项目需求文档

## 1. 项目概述

QtScrcpy 是一款基于 Genymobile 的 scrcpy 项目重构的开源工具，使用 C++ 和 Qt 框架实现 Android 设备屏幕的实时投屏与控制。它无需 root 权限，支持跨平台（Windows、macOS、Linux），专注于轻量、高性能、低延迟和高质量的画面传输。

### 1.1 项目背景

QtScrcpy 基于 Genymobile 的 scrcpy 项目进行复刻和重构，使用 Qt 替代 SDL 实现图形界面，使用 OpenGL 进行视频渲染，以提供更友好的图形界面和更灵活的定制能力。

### 1.2 项目目标

- 提供比原生 scrcpy 更友好的图形界面（基于 Qt 而非 SDL）
- 支持自定义按键映射，提升游戏和应用的操作体验
- 实现多设备批量控制与无线连接
- 降低 CPU 占用，提高渲染性能（使用 OpenGL 渲染）

## 2. 功能需求

### 2.1 基础功能

#### 2.1.1 设备连接
- **USB 连接**: 支持通过 USB 线缆连接 Android 设备
- **无线连接**: 支持通过 Wi-Fi 连接 Android 设备
- **多设备支持**: 支持同时连接多个 Android 设备
- **设备管理**: 支持设备列表的刷新、选择和管理

#### 2.1.2 屏幕显示
- **实时显示**: 实时显示 Android 设备屏幕内容
- **高分辨率支持**: 支持 1920×1080 或更高分辨率
- **全屏模式**: 支持窗口全屏显示
- **窗口置顶**: 支持将显示窗口保持在最顶层
- **去除黑边**: 支持自动调整窗口大小以去除黑边
- **1:1 显示**: 支持像素级完美显示（1:1 比例）

#### 2.1.3 控制功能
- **鼠标控制**: 支持鼠标点击、滑动等操作映射到设备
- **键盘控制**: 支持键盘按键映射到设备功能键
- **快捷键支持**: 支持多种快捷键操作（HOME、BACK、音量调节等）
- **触控模拟**: 模拟触摸屏操作

### 2.2 高级功能

#### 2.2.1 录制与截图
- **屏幕录制**: 支持录制设备屏幕为视频文件
- **后台录制**: 支持在不显示界面的情况下录制屏幕
- **截图功能**: 支持截取屏幕为 PNG 图片

#### 2.2.2 文件传输
- **APK 安装**: 支持拖拽 APK 文件到窗口进行安装
- **文件传输**: 支持拖拽普通文件到窗口传输到设备

#### 2.2.3 剪贴板同步
- **双向同步**: 支持计算机和设备之间的剪贴板同步
- **复制操作**: `Ctrl + c` 将设备剪贴板复制到计算机
- **粘贴操作**: `Ctrl + Shift + v` 将计算机剪贴板复制到设备
- **文本注入**: `Ctrl + v` 将计算机剪贴板作为文本事件发送到设备

#### 2.2.4 自定义按键映射
- **脚本支持**: 支持编写自定义按键映射脚本
- **游戏支持**: 针对游戏提供键盘鼠标到触控的映射
- **脚本管理**: 支持加载、应用和切换自定义映射脚本

#### 2.2.5 群控功能
- **批量控制**: 支持同时控制多个连接的设备
- **群控操作**: 对所有设备执行相同操作

#### 2.2.6 音频同步
- **音频传输**: 支持将设备音频同步到计算机（基于 sndcpy，Android 10+）

### 2.3 界面功能

#### 2.3.1 主界面功能
- **启动配置**: 提供启动服务前的参数设置
- **设备管理**: 提供设备列表和连接状态管理
- **服务控制**: 提供启动、停止服务的控制
- **网络连接**: 提供无线连接相关功能

#### 2.3.2 配置选项
- **比特率设置**: 可设置视频传输的比特率
- **分辨率设置**: 可设置视频传输的分辨率
- **录制格式**: 可选择录制视频的格式
- **保存路径**: 可设置录制文件的保存路径

## 3. 技术需求

### 3.1 系统要求

#### 3.1.1 操作系统支持
- **Windows**: 支持 Windows 7 及以上版本
- **macOS**: 支持 macOS 10.12 及以上版本
- **Linux**: 支持主流 Linux 发行版

#### 3.1.2 Android 设备要求
- **Android 版本**: 至少需要 Android 5.0 (API 21)
- **ADB 调试**: 需要在设备上启用 ADB 调试

### 3.2 性能要求

- **启动时间**: 启动时间小于 1 秒
- **延迟**: 35~70ms（USB 连接延迟更低）
- **帧率**: 30~60fps
- **分辨率**: 支持 1080p 以上分辨率
- **CPU 占用**: 尽可能降低 CPU 占用率

### 3.3 技术架构

#### 3.3.1 客户端-服务器模型
- **客户端**: 运行在 PC 上，负责 UI 显示、输入事件转发、视频解码与渲染
- **服务器端**: 运行在 Android 设备上，采集屏幕数据并编码为 H.264 流

#### 3.3.2 技术栈
- **前端**: Qt 5.12+ (C++)
- **GUI 框架**: Qt Widgets + OpenGL
- **视频解码**: FFmpeg
- **视频渲染**: OpenGL (QOpenGLWidget)
- **音频同步**: sndcpy (独立脚本集成)
- **构建系统**: CMake / qmake
- **脚本语言**: JSON（用于键位映射）
- **网络通信**: ADB 协议 + Socket

### 3.4 设计模式

- **工厂模式**: 用于创建不同平台的 MouseTap 实例（Win/Mac/X11）
- **单例模式**: Config 类全局配置管理
- **观察者模式**: 设备状态更新通知 UI
- **策略模式**: 键位映射脚本动态加载执行

## 4. 用户界面需求

### 4.1 主界面布局

主界面应包含:
- 设备列表区域
- 视频显示窗口
- 控制按钮区域
- 配置设置区域

### 4.2 操作流程

1. **设备连接流程**:
   - 连接 Android 设备到计算机
   - 运行程序
   - 点击 "USB 连接" 或 "WiFi 连接"

2. **无线连接流程**:
   - 确保手机和计算机在同一局域网
   - 启用设备开发者选项中的 ADB 调试
   - USB 连接设备
   - 获取设备 IP
   - 启动 adbd 服务
   - 执行无线连接

### 4.3 快捷键支持

| 功能 | Windows 快捷键 | macOS 快捷键 |
|------|----------------|--------------|
| 全屏切换 | Ctrl+f | Cmd+f |
| 1:1 显示 | Ctrl+g | Cmd+g |
| 去除黑边 | Ctrl+w / 双击 | Cmd+w / 双击 |
| HOME 键 | Ctrl+h / 中键 | Ctrl+h / 中键 |
| BACK 键 | Ctrl+b / 右键 | Cmd+b / 右键 |
| APP_SWITCH | Ctrl+s | Cmd+s |
| 音量增加 | Ctrl+↑ | Cmd+↑ |
| 音量减少 | Ctrl+↓ | Cmd+↓ |
| 电源键 | Ctrl+p | Cmd+p |
| 关闭屏幕 | Ctrl+o | Cmd+o |

## 5. 安全和隐私要求

- 不在设备上永久安装任何组件
- 仅通过 ADB 调试接口通信，需用户授权
- 本地运行，无数据上传到外部服务器
- 仅在用户主动操作时进行设备控制

## 6. 兼容性要求

- 兼容主流 Android 设备
- 支持不同分辨率和屏幕比例的设备
- 支持不同 Android 版本（API 21+）
- 跨平台兼容（Windows/macOS/Linux）
